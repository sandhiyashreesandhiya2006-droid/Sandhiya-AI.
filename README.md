# 🤖 Sandhiya AI

An AI-powered Document Intelligence & Analytics Platform built using Python and Streamlit.

## 📌 Overview

Sandhiya AI is an intelligent assistant that helps users analyze documents, summarize content, answer questions, generate interview questions, perform web search, and interact with AI through an easy-to-use interface.

## ✨ Features

- 🤖 AI Chat Assistant
- 📄 AI Document Summarization
- 📂 Supports PDF, DOCX, CSV, Excel & TXT
- 📊 Dataset Preview & Analysis
- 🌐 Web Search Integration
- 🎯 AI Interview Question Generator
- 💬 Chat History Management
- 📥 Download Chat History
- 🔐 Secure Login Authentication

## 🛠 Technologies Used

- Python
- Streamlit
- Google Gemini API
- Pandas
- PyPDF2
- python-docx
- Pillow
- Requests

## 🚀 Installation

```bash
git clone https://github.com/sandhiyashreesandhiya2006-droid/Sandhiya-AI.git
cd Sandhiya-AI
pip install -r requirements.txt
streamlit run app.py
```
