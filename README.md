Sandhiya AI

Sandhiya AI is an intelligent chatbot built using Streamlit and Google Gemini AI.

Features

- AI Chat Assistant
- File Upload (CSV, Excel, PDF, DOCX, TXT)
- Dataset Summary
- Current Affairs Search
- Chat Download
- Tamil and English Support

Technologies Used

- Python
- Streamlit
- Google Gemini API
- Pandas
- PyPDF2
- Python-docx
